# vectribe-bot

Discord AI agent built for **Vectribe** (vectribeagency.com) — web design, SEO & digital marketing, Birmingham UK.

## What it does

- **Same-brain AI chat** — grounded answers with live web search (no fabricated leads, ever)
- **Lead hunting** — finds real businesses, drafts outreach, sends emails
- **Zapier MCP** — 130+ connected actions: HubSpot, Gmail, GitHub, Google Analytics, Apollo, Facebook Pages
- **Productivity** — reminders, notes, tasks, daily brief (Asia/Karachi timezone)
- **Slash commands** — /ask /search /image /tts /translate /summarize /reset /setairoom /setbrief /zapier and more (15 total)
- **Agent memory** — activity log + facts store, so "what were we doing?" gets a real answer

## Run

Node 18+. All configuration is via environment variables (see `.env.example`).
Deploys on Railway with auto-deploy from `main`.
